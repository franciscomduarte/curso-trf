Feature 1 de 5

O problema sem Plan Mode

Quando você dá uma instrução sem planejar, Claude executa imediatamente. Em projetos complexos, corrige uma coisa e quebra outra.

Como funciona

  • 01
    Claude analisa tudo

    Le o projeto inteiro e apresenta um plano detalhado antes de tocar em qualquer arquivo

  • 02
    Você le, aprova ou ajusta

    Pode aprovar, pedir revisao ou mandar repensar partes especificas do plano

  • 03
    So depois ele executa

    A implementacao acontece apenas apos aprovacao explícita do plano

Use Plan Mode. Sempre.

Para qualquer coisa que não seja trivial.

Feature 5 de 5

Memória e contexto

A context window é a mesa de trabalho do Claude. Quanto mais papéis empilha, mais difícil encontrar o que precisa.

🗂️

Context window = mesa de trabalho
Quanto mais cheia, pior o resultado

50% = limpar /clear /compact

3 comandos essenciais

/clear

Limpar tudo

Nova tarefa. Comece do zero. Contexto completamente resetado.

/compact

Compactar

Resume o contexto sem perder o essencial. Ideal para tarefas longas.

/context

Ver uso

Mostra o uso dá context window. Acima de 50%, hora de limpar.

Uso Avançado

Skills customizadas

Tarefas repetitivas viram um comando: /deploy, /post, /relatório. Você define a sequência uma vez, executa com uma palavra.

Seu próprio playbook de IA

Hooks de segurança

Regras automáticas antes e depois de ações. rm -rf bloqueado. Deploy com aprovacao obrigatória. Dados sensíveis com log automático.

"A autonomia que você dá é proporcional a confiança que você constroi."

Extended thinking (ultrathink)

Inclua "ultrathink" no prompt para raciocínio profundo. Usar para arquitetura e decisoes que afetam muitas partes. Não usar para tarefas simples.

Loop de verificação

Inclua verificação na instrução: "Implemente e depois rode os testes." Claude entrega, verifica, encontra problemas e corrige antes de mostrar.
