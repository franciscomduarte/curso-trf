# Aula 0 · Checklist do instrutor

## Antes da aula

- [ ] XAMPP instalado e funcionando em todas as máquinas (Apache + MySQL rodando)
- [ ] Acesso a uma ferramenta de IA (Claude Code ou alternativa gratuita) testado em pelo menos uma máquina de cada sala/bancada
- [ ] Pasta do projeto (`htdocs/sisprot`) criada e vazia em todas as máquinas
- [ ] phpMyAdmin acessível (para rodar o `schema.sql` e as migrações dos exercícios)
- [ ] Projetor/segunda tela testado para as demonstrações ao vivo
- [ ] Arquivo `prompts.md` aberto e pronto para copiar/colar durante as demos
- [ ] `exercicios.md` distribuído (impresso, ou link/arquivo compartilhado) — sem `solucoes.md` visível aos alunos
- [ ] Cronômetro ou relógio visível para controlar os blocos de tempo

## Durante a aula

- [ ] Abertura: apresentar o curso completo (4 aulas) e o projeto SISPROT como fio condutor
- [ ] Demonstração 1: rodar o prompt fraco primeiro, deixar a turma reagir ao resultado genérico, só depois mostrar o prompt estruturado
- [ ] Antes do Exercício 1: confirmar que todos conseguiram reproduzir a Demonstração 1 (schema + conexão funcionando)
- [ ] Demonstração 2: destacar a equivalência XML ↔ Markdown prompting — não é sintaxe mágica, é estrutura inequívoca
- [ ] Antes do Exercício 2: confirmar que todos têm o CRUD completo funcionando
- [ ] Circular entre bancadas durante os exercícios — a dificuldade mais comum é prompt ainda ambíguo, não erro de código
- [ ] Reservar os últimos 10 minutos da aula para o desafio final + preview da Aula 1
- [ ] Pedir que cada aluno salve os prompts usados nos exercícios — serão reaproveitados como base de discussão na Aula 1

## Ao final da aula

- [ ] Confirmar que todos saem com o SISPROT funcionando (CRUD completo, pelo menos até o Exercício 1)
- [ ] Recolher (ou pedir para os alunos guardarem) os prompts do desafio final, para eventual discussão no início da Aula 1
- [ ] Anotar dúvidas recorrentes não previstas em `faq.md`, para enriquecer o material antes da próxima turma
