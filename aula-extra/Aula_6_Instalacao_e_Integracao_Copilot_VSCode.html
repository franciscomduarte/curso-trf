Etapa 1

Instalando o Visual Studio Code

O editor que usaremos em todas as aulas do curso — leve, gratuito e com suporte nativo a extensões como o GitHub Copilot.

O que é o VS Code

O Visual Studio Code (VS Code) é um editor de código-fonte gratuito e multiplataforma, mantido pela Microsoft. Ele roda em Windows, macOS e Linux, e será a base de todo o trabalho prático do curso — inclusive da integração com o GitHub Copilot.

Instalação

Download e instalação do VS Code

~5 min
Passo 1

Baixe o instalador

  1. Acesse code.visualstudio.com/download.
  2. O site detecta automaticamente seu sistema operacional; clique no botão de download correspondente (Windows, macOS ou Linux).
Passo 2

Execute o instalador

  • Windows: execute o .exe baixado. Aceite os termos e, na tela de tarefas adicionais, marque "Adicionar ao PATH" — isso permite abrir o VS Code pelo terminal com o comando code.
  • macOS: extraia o .zip e arraste o ícone do VS Code para a pasta Applications.
  • Linux: instale o pacote .deb (Debian/Ubuntu) com sudo apt install ./code_*.deb ou o .rpm (Fedora/RHEL) com o gerenciador de pacotes da distribuição; também há build via snap install code --classic.
Passo 3 (recomendado)

Instale o Git

O Git é o programa de controle de versão que o VS Code usa por trás dos panos para conversar com o GitHub (clonar, enviar e sincronizar repositórios). Sem ele, a integração com o GitHub dentro do editor fica limitada.

  1. Baixe em git-scm.com/downloads e instale com as opções padrão sugeridas pelo instalador.
Passo 4

Confirme a instalação

Abra um terminal (Prompt de Comando, PowerShell ou Terminal) e rode os comandos abaixo. Cada um deve responder com um número de versão:

# confirma o VS Code code --version # confirma o Git git --version
  • ✓VS Code instalado e abre normalmente.
  • ✓Comando code --version reconhecido no terminal.
  • ✓Git instalado e git --version reconhecido no terminal.
Dica

Se o comando code não for reconhecido no terminal após a instalação, feche e reabra o terminal (ou o computador). No Windows, também é possível adicionar o VS Code ao PATH manualmente pela paleta de comandos: abra o VS Code, pressione Ctrl+Shift+P e busque por "Shell Command: Install 'code' command in PATH".

Etapa 2

Criando uma conta no GitHub

O GitHub é onde o código do curso pode ser versionado e é também a conta usada para autenticar o GitHub Copilot.

O que é o GitHub

O GitHub é uma plataforma de hospedagem de repositórios Git na nuvem — usada para guardar, versionar e colaborar em código. Além disso, uma conta GitHub é o único requisito para habilitar o GitHub Copilot, inclusive no plano gratuito.

Cadastro

Criação da conta

~5 min
Passo 1

Acesse a página de cadastro

  1. Vá até github.com/signup.
Passo 2

Preencha os dados

  1. Informe um e-mail pessoal válido.
  2. Crie uma senha forte (o GitHub indica os critérios mínimos na hora do cadastro).
  3. Escolha um nome de usuário — ele aparecerá em URLs públicas, então evite dados sensíveis.
  4. Resolva a verificação de segurança (captcha/puzzle) apresentada na tela.
Passo 3

Confirme o e-mail e escolha o plano

  1. Digite o código de verificação enviado ao seu e-mail.
  2. Quando perguntado sobre o plano, escolha Free — é o suficiente para todo o curso, incluindo o uso do Copilot.
  • ✓Conta criada e e-mail confirmado.
  • ✓Login funcionando em github.com/login.
  • ✓Nome de usuário e senha anotados em um local seguro.
Recomendado

Ative a autenticação em dois fatores (2FA) assim que a conta for criada, em Settings → Password and authentication. Veja o passo a passo oficial em docs.github.com — 2FA. Isso protege a conta que, a partir de agora, também autentica o Copilot.

Etapa 3

Instalando e integrando o GitHub Copilot no VS Code

Com o editor instalado e a conta GitHub em mãos, falta o último passo: ligar as duas coisas através da extensão do Copilot.

O que é o GitHub Copilot

O GitHub Copilot é um assistente de programação com IA que sugere trechos de código diretamente no editor, com base no contexto do arquivo, e oferece um chat (Copilot Chat) para tirar dúvidas, explicar código e gerar esboços de implementação.

Sobre o custo

O GitHub oferece um plano Copilot Free, vinculado à própria conta GitHub, sem cartão de crédito — com um número limitado de sugestões e interações de chat por mês. Isso é suficiente para acompanhar este curso. Consulte os limites e planos pagos em github.com/features/copilot/plans.

Instalação e login

Extensão, autenticação e primeiro teste

~10 min
Passo 1

Instale a extensão dentro do VS Code

  1. Abra o VS Code e a paleta de comandos com Ctrl+Shift+P (Cmd+Shift+P no Mac).
  2. Escolha Extensões: Instalar Extensões e pesquise por GitHub Copilot.
  3. Clique em Instalar na extensão oficial da GitHub (publisher: GitHub). Ela já inclui o Copilot Chat.

Alternativa: instale diretamente pelo navegador, na página da extensão no Marketplace — marketplace.visualstudio.com/.../GitHub.copilot — e clique em Install, o que abre o VS Code automaticamente.

Passo 2

Faça login com a conta GitHub

  • Clique no ícone de conta (silhueta de pessoa) no canto inferior esquerdo do VS Code e selecione a opção para entrar com o GitHub; ou
  • Abra a paleta de comandos e busque por "GitHub Copilot: Sign In".
  • O navegador abrirá a página de autorização do GitHub — confirme com a conta criada na Etapa 2 e conceda as permissões solicitadas.
  • Volte ao VS Code: o ícone do Copilot na barra de status (canto inferior direito) deve aparecer ativo.
Passo 3

Teste a primeira sugestão

Crie um arquivo de teste qualquer (ex.: teste.js) e escreva um comentário de intenção. O Copilot deve sugerir o código em cinza, logo abaixo:

// função que valida um CPF

Pressione Tab para aceitar a sugestão, ou Esc para descartá-la.

  • ✓Extensão GitHub Copilot instalada no VS Code.
  • ✓Login realizado e ícone do Copilot ativo na barra de status.
  • ✓Uma sugestão inline foi exibida e aceita com sucesso.
  • ✓Painel do Copilot Chat abre normalmente (ícone de chat na barra lateral).

Boas práticas desde já: use o Copilot como assistente, não como autor final — revise toda sugestão antes de aceitar. Isso vale ainda mais dentro do SISPROT, o projeto do curso, onde qualidade e segurança do código são parte da avaliação.
